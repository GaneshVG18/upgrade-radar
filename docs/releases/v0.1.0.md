# Upgrade Radar v0.1.0 preview

This prerelease ships the first working Upgrade Radar implementation: a TypeScript library/CLI, composite GitHub Action, standalone evidence report, Express 4.21.2 → 5.1.0 and Zod 3.25.76 → 4.1.5 adapters, and a 48-case authored compatibility corpus.

The deterministic baseline, demo, engineering tests, and compatibility assertions are release-gated. Optional live Jev support is implemented, but the full family-split private semantic evaluation had not yet been completed for this release, so it is intentionally marked prerelease and makes no public model-accuracy/performance claim.

See `docs/limitations.md`, `docs/privacy.md`, and `docs/evaluation.md` before enabling live mode.
