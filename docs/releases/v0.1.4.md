# Upgrade Radar v0.1.4 preview

This prerelease hardens Upgrade Radar against false-complete results discovered while exercising real local Express and Zod consumers rather than only the repository's own test suite.

Key fixes:

- the normal local path is now `upgrade-radar review`: repo, refs, bundled reviewed notes, baseline provider, and output location all have safe defaults;
- GitHub Action users no longer need to provide base/head/notes/provider after a full-history checkout; those inputs remain available as overrides;
- Git-installed/npx packaging now builds itself and includes its bundled notes; `typescript` is correctly shipped as a runtime dependency because the analyzer imports the TypeScript compiler API at runtime;
- dependency changes without applicable reviewed notes remain visible, become explicit unknown coverage gaps, mark the report incomplete, and return exit code `2`;
- malformed `notes-manifest.json` falls back to note discovery while preserving unverified provenance and incomplete status;
- dynamic imports and resolvable computed package references become explicit unsupported-reference unknowns instead of allowing an empty falsely complete report;
- repositories without `origin` no longer emit Git error noise;
- GitHub and GitLab revision-pinned evidence links use the correct host-specific URL shape, while unsupported hosts fail closed;
- the CLI now provides `--help`/`-h` output.

The hardening pass also exercised real Express `4.21.2 → 5.1.0` query-parser behavior, Zod `3.25.76 → 4.1.5` optional-default behavior, combined multi-package upgrades, explicit negative controls, imported configuration ambiguity, baseline mode, live Jev mode, provider failure, and standalone report interaction in Chrome.

Audit note: the development dependency `express4` intentionally aliases `express@4.21.2` so the compatibility corpus can execute the pre-upgrade behavior. A full `npm audit` therefore reports advisories in that fixture-only Express 4 dependency graph. `npm audit --omit=dev` is clean, and the pinned Express 4 package is not part of Upgrade Radar's shipped runtime dependencies.

Semantic routing remains experimental. Private live evaluation artifacts and metrics remain ignored and are not attached to this release, so v0.1.4 remains a prerelease.
