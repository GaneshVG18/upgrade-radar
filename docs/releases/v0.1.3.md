# Upgrade Radar v0.1.3 preview

This prerelease closes the composite-Action release-gate proof: CI now invokes `uses: ./` against a synthetic local Express 4→5 Git history, verifies all three generated report formats, and exercises the Action's artifact upload and job-summary path without provider secrets.

The Action also accepts an optional local `repo` path for already-checked-out repositories; when omitted it continues to analyze `GITHUB_WORKSPACE`.

Semantic routing remains experimental. Private live evaluation artifacts and metrics remain ignored and are not attached to this release.
