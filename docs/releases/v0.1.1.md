# Upgrade Radar v0.1.1 preview

This prerelease tightens evidence and evaluation completeness without changing the project's advisory scope.

- Evidence IDs are clone-independent and code rows can link to the exact analyzed commit when a supported origin remote is available.
- The 48-case Express/Zod corpus now has one isolated fixture directory per case plus a SHA-256 provenance manifest.
- Engineering tests cover additional failure, privacy, source-safety, Git-object, and exit-code paths.
- The live evaluation runner now uses tracked labels and the real adapters to compare baseline and Jev over the same retrieved candidate inventory while keeping development and held-out families separate.

Private live evaluation artifacts and summaries remain under ignored `.private-evals/` and are not attached to this release. Semantic routing remains experimental; the deterministic baseline remains available. See `docs/limitations.md`, `docs/evaluation.md`, and `docs/privacy.md`.
